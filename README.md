# Vine Generator Documentation

Vine Generator is a native Unreal Engine plugin by FunByDefault for climbing, branching and hanging plants.

[Open the guide](https://funbydefault.github.io/vine-generator-docs/DOCUMENTATION.html) for setup, growth guides, pruning, foliage, Static Mesh export, runtime preparation and troubleshooting.

[Reclaimed tour and controls](RECLAIMED_DEMO.md) covers the example map, keyboard and mouse, gamepad mappings and Windows touchscreen controls.

Use the plugin package built for your Unreal Engine version. The paid plugin source is distributed separately and is not included in this documentation repository.
